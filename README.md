# Cloud Cost Janitor

An agent, built on [TrueForge](https://trueforge.dev), that finds idle instances, orphaned volumes and
forgotten load balancers in a real AWS account, prices the waste, drafts a teardown plan, and deletes
resources **only after a human approves each deletion**.

> Work in progress — built for the *Agents That Act* hackathon (TrueFoundry × Polaris, 26 Sep 2026).
> See [`PLAN.md`](PLAN.md) for the architecture and build steps. The full README lands with step 11.
